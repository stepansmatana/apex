Third public release. Major expansion — new modules,
7 visual themes, English localization, 1–10 scale,
and tons of quality-of-life improvements.

───────────────────────────────────────────────────────────
  INSTALLATION
───────────────────────────────────────────────────────────

  Download Apex_1.1.0_x64-setup.exe and run it.
  The app installs itself including a desktop shortcut.
  No dependencies, no registration.

  Data from previous versions is automatically migrated.

───────────────────────────────────────────────────────────
  CHANGELOG 1.1.0
───────────────────────────────────────────────────────────

  NEW FEATURES
  · Weight tracker — logging, trend chart, min/max/delta
  · Mood & Energy in Lifestyle — retroactive entry
    with the same UI as other health records
  · Onboarding wizard — first-launch setup guide
    (name, modules, first habit)
  · Drag & drop task reordering — custom order
    with persistent storage
  · Undo toast — after deleting a task, goal, habit, note
    or book you get 5 seconds to undo
  · Streak stats — current streak 🔥 + best streak ever
    🏆 for each habit
  · Sunday reminder — dashboard banner reminds you
    to write your weekly review
  · Interactive chart tooltips — hover over a chart
    to see date and value
  · CSV export — per-module data export (mood, sleep,
    habits, weight, tasks, focus)
  · Auto backup — JSON backup every 7 days
    (desktop version only)

  VISUAL THEMES (7 THEMES)
  · Zeus — ancient Greece, gold accents, Cinzel font
  · Neon — cyberpunk, neon colors, JetBrains Mono
  · Zen — Japanese minimalism, muted tones, Noto Serif
  · Terminal — retro CRT, green on black, scanline effect
  · Obsidian — ultra-premium dark, minimalist
  · Rosé — feminine pink, Quicksand font
  · Lavender — feminine purple, soft gradients
  · Each theme has its own dark and light variant

  LOCALIZATION
  · English (US) localization — switchable in settings
  · Complete translation of all 280+ text strings
  · Locale-aware date and chart formatting

  MOOD & ENERGY SCALE
  · Expanded from 1–5 to 1–10 for finer granularity
  · Old data is automatically rescaled (×2)
  · 10 emojis for mood, 10 numbered buttons for energy

  KEYBOARD SHORTCUTS
  · Ctrl+N — new task
  · Ctrl+S — save
  · Q — quick thought capture
  · 1–9 — switch sections
  · Esc — close modal

  FADE ANIMATIONS
  · Smooth section transitions (fade + slide)
  · Modals with scale-in effect
  · Lifestyle tabs with fade transition

  PERFORMANCE
  · Async loading of theme-specific fonts
  · backdrop-filter blur only on open modals
  · Animation pausing on hidden sections
  · Elimination of all transition: all rules

  BUGFIXES
  · 50+ bugs fixed across all modules
  · XSS protection on all user inputs
  · Timezone-safe date operations (localDateStr)
  · Timer records actual time, not configured duration
  · TickTick import correctly maps priorities
  · Save lock on all forms to prevent double-click
  · Null guards on DOM operations
  · Correct task ordering after import

  CHANGELOG 1.0.1
  · Long-term goals can now be set for specific periods
  · Tasks now support custom tags
  · TickTick tasks are imported together with tags
  · Backward compatibility with saved data from 1.0.0
  · Bugfixes

───────────────────────────────────────────────────────────
  WHAT APEX CAN DO
───────────────────────────────────────────────────────────

  DASHBOARD
  · Daily mood check-in (1–10) and energy (1–10)
  · Overview of today's tasks, focus hours, sleep & habits
  · Streak badge on habits right on the dashboard
  · Quick thought capture (press Q)
  · Sunday reminder for weekly review

  DAILY TASKS
  · Three priority levels (High / Medium / Low)
  · Drag & drop for custom ordering
  · Custom tags compatible with TickTick import

  · Secondary and main tasks for today
  · Edit, description, recurrence (daily, weekdays,
    custom days)

  GOALS
  · Long-term goals split into weekly, monthly,
    quarterly and yearly
  · Milestones with progress tracking
  · Lower goals always lead to higher ones — clear
    hierarchy toward life goals
  · Weekly review with reflection

  FOCUS TIMER
  · Classic pomodoro timer with work blocks and breaks
  · Motivational quotes in Czech and English
  · Automatic tracking — see how many hours
    you spent in deep focus

  HABITS
  · Track good and bad habits
  · Current streak + best streak ever
  · Correlate with lifestyle data through charts

  LIFESTYLE
  · Workouts, sleep, mood & energy, Elonga,
    supplements, weight, health calendar
  · Everything visualized in charts — track the
    long-term development of your well-being

  ANALYTICS
  · Interactive charts with hover tooltips
  · Mood, energy, sleep, focus and habits
  · Customizable period (7 days, 14 days, month, custom)
  · See how your lifestyle affects your performance
    (and how substances wreck your life)

  NOTES & THOUGHTS
  · Classic notes for longer entries
  · Quick thought capture — delete or convert to notes

  READING
  · Book database — want to read / reading / finished
  · Author, rating, notes

  JOURNAL
  · Daily journal with date

  EXPORT & IMPORT
  · JSON data backup with one click
  · CSV export per module (mood, sleep, habits,
    weight, tasks, focus)
  · Automatic backup every 7 days
  · Easy data transfer when switching computers

  SETTINGS
  · 8 visual themes (default + 7 unique)
  · Dark mode / light mode for each theme
  · Czech / English
  · Enable/disable individual modules
  · Custom name on dashboard
